# Scenarios

One TOML file per scenario; `../vnapctl scenarios` lists them, `../vnapctl up <name>` starts
one. `templates/` holds the scenarios the service offers its users.

- **The format:** [docs/reference/scenario-format.md](../../docs/reference/scenario-format.md)
  (also `../vnapctl schema`).
- **Which scenario does what:** [docs/operations/vnapctl.md](../../docs/operations/vnapctl.md#walkthrough).
