# Scenarios

Five foundational scenarios, one per phenomenon: `trust`, `linkability`, `crossing`, `convoy`
and `refill`. Each has variants (`[variants.<name>]`, started as `../vnapctl up crossing:min3`).
`controls/` holds pass/fail controls; `templates/` links the scenarios the service offers its
users. `../vnapctl scenarios` lists them all.

- **The format:** [docs/reference/scenario-format.md](../../docs/reference/scenario-format.md)
  (also `../vnapctl schema`).
- **Which scenario does what:** [docs/operations/vnapctl.md](../../docs/operations/vnapctl.md#walkthrough).
